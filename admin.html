Entrar al panel

El panel guarda los cambios en tu repositorio de GitHub y Vercel actualiza el sitio solo. Para entrar necesitas un token de GitHub con permiso para escribir en el repositorio .

Cómo crear el token (una sola vez)
  1. Entra a GitHub → Settings → Fine-grained tokens.
  2. En Repository access elige Only select repositories y marca solo .
  3. En Permissions → Repository permissions, pon Contents en Read and write.
  4. Crea el token, cópialo y pégalo aquí.
