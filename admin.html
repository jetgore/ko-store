Panel de administración

Entrar al panel

El panel guarda los cambios en tu repositorio de GitHub y Vercel actualiza el sitio solo. Para entrar necesitas un token de GitHub con permiso para escribir en el repositorio .

Cómo crear el token (una sola vez)
  1. Entra a GitHub → Settings → Fine-grained tokens.
  2. En Repository access elige Only select repositories y marca solo .
  3. En Permissions → Repository permissions, pon Contents e Issues en Read and write (Issues es para revisar los comentarios).
  4. Crea el token, cópialo y pégalo aquí.

      Simulador de importación

      Costo puesto en Chile y margen por producto. Los escenarios se guardan solo en este navegador.

      Supuestos del pedido

      Los gastos (flete, seguro, arancel, agente, etc.) se reparten según el valor FOB de cada producto. El arancel 0 % del TLC Chile–China exige el certificado de origen del proveedor. Gastos en Chile: retiro del puerto, despacho a bodega, etc. El IVA de la importación no se suma al costo porque se recupera como crédito fiscal.

      Productos del pedido

      FOB = precio unitario del proveedor en dólares. Venta = tu precio con IVA. "Precio sugerido" es el precio con IVA que da el margen objetivo.
